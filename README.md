# Cognitive Arena

A web-based cognitive testing suite built to benchmark reaction speed, aim accuracy, visual and number memory, and continuous typing WPM in your browser.

## Quick Start
Open the live demo link above to launch the application instantly in your browser—no installation required.

## Features
* **Reaction Speed:** Measures visual processing time when clicking green cues.
* **Aim Trainer:** Tests mouse control and flicking speed across 15 randomized targets.
* **Visual Memory:** Trains spatial recall on a dynamic 4x4 tile grid.
* **Number Memory:** Tests digit sequence retention capacity under time limits.
* **Typing Speed:** Continuous 30-second test with a stream of words.

## Display & Preview
Built with a sleek synthwave theme featuring dark backgrounds, purple and white text, interactive menu hover states, and dynamic color coded state shifts
